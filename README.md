# Hospital_Management
A Java-based desktop application designed to streamline the operations of hospitals by managing patients, doctors, appointments, billing, and medical records efficiently.

📌 Features
👨‍⚕️ Doctor Management – Add, view, update, and delete doctor records.

🧑‍🤝‍🧑 Patient Management – Add new patients, maintain patient history, and discharge summary.

🔐 Login System – Secure login for admin, doctor, and staff roles.

🛠️ Tech Stack
Programming Language: Java

GUI: Java Swing

Database: MySQL

Database Connectivity: JDBC

IDE:  IntelliJ IDEA
